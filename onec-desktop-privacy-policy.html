ONEC Desktop Privacy Policy

Updated: November 22, 2026 · Version 0.1.0-beta.1

Developer and contact

ONEC Desktop is a free Windows desktop application developed by PHO IENG, an individual developer in Cambodia, and distributed through the Microsoft Store. This policy describes version 0.1.0-beta.1, a beta for learning and research. For privacy questions or support, contact iengpho@gmail.com.

No developer data collection through the app

ONEC Desktop does not automatically send personal information, project contents, prompts, usage analytics or diagnostic reports to the developer. It has no user accounts, advertising, purchases or subscriptions, and the developer does not sell your personal information or use the app to track you. The one exception is a model address operated by the developer, if you choose to use one; it is described below.

What is stored on your computer

  • Your projects, chat history, tasks, memories, run history, approvals and settings, in a folder named .oneconsole in your Windows user profile.
  • API keys and connection details you add, in a configuration file that only your Windows account (and the system) can read. They are not sent to the developer.
  • Application logs, in the ONE Console folder under your local application data, to help find problems.

Nothing in this list is uploaded unless you set up one of the connections described next.

What leaves your computer

Only what you set up or ask for:

  • AI model providers. The text you write, the files and results the assistant reads, and the conversation context are sent to the model provider you choose: an OpenAI-compatible service, Anthropic, or a model running on your own computer through Ollama. Requests use your own key and are subject to that provider's terms and privacy policy. If you enter a model address operated by the developer, your requests pass through the developer's server to a model provider, and that server can see them while they are handled.
  • Coding agents. If you add agents such as Codex or Claude, ONEC Desktop starts their command-line tools on your computer in the project folders you choose. They talk to their own providers under their own terms. ONEC Desktop asks for your approval before each file change or command.
  • Remote workers and hosts. If you connect a remote host, the tasks, context and files you give that worker are sent to it.
  • The web. If you ask the assistant to fetch a web page, that website sees the request.
  • Microsoft. Downloading and updating the app through the Microsoft Store, and the Microsoft Edge WebView2 Runtime that displays the app window, are handled by Microsoft under its own privacy statements. ONEC Desktop does not control them.

Your approvals

Every file change and command from an assistant or worker needs your approval. Nothing is approved in advance unless you choose Always allow, which saves a rule on your computer that you can revoke in Settings.

Security

The app's own web interface listens only on your computer's loopback address and requires a random token. Keys are protected by Windows file permissions, which do not protect against someone who has access to your Windows account or administrator rights. Do not put anything in a prompt or a project that you cannot accept being sent to the model provider you chose.

Retention and deletion

Your data stays on your computer until you remove it. You can delete projects, memories and snapshots in the app. To remove everything, uninstall the app and delete the .oneconsole folder in your user profile and the ONE Console folder in your local application data. The developer holds no copy to delete. If you write to the developer, the correspondence is kept only as long as needed to answer you.

Children

ONEC Desktop is intended for adults and learners aged 13 and older. It is not directed to children under 13.

Beta and changes

This is a beta for learning and research and is not for production or company use. If this policy changes in a way that matters, the new version is published on this page and the app asks you to accept the updated terms again.
