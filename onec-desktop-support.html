ONEC Desktop Support

What it is

ONEC Desktop is a free Windows desktop app that brings an AI assistant and your coding agents (such as Codex and Claude) into one window, for the project folders you choose. Every file change and command from a worker needs your approval. This version is a beta for learning and research, not for production or company use.

What you need

  • Windows 10 (version 1809 or later) or Windows 11, 64-bit, with the Microsoft Edge WebView2 Runtime (included with Windows 11).
  • A model for the assistant: an API key from a provider, or Ollama running on your own computer. Without one the assistant cannot answer.
  • Optional: the Codex or Claude command-line tools, installed and signed in on your computer. ONEC Desktop does not install them or sign you in.
  • Optional: Git, only for isolated edits that you review before applying.

First steps

  • Open ONEC Desktop and accept the terms.
  • Run setup: add the coding agents found on your computer and the assistant's model, then press Save and test.
  • Create a project by choosing a folder you are happy for the assistant and workers to work in.
  • Chat with the assistant, or create tasks and assign them to workers. Run setup again any time from Settings, About & legal, Getting started.

Common problems

  • The assistant does not answer. Add a model in the setup or in Settings, Connections, Models and Assistant models, and check the key and address with Save and test.
  • A coding agent is not found. Install it and sign in on your computer, then press Scan for agents in Settings, Agent workers.
  • The window does not open. Install the Microsoft Edge WebView2 Runtime from Microsoft, then start the app again.
  • Something looks wrong. Open Settings, Doctor.

Your data

Your projects, chats, tasks and settings stay on your computer. To remove them, uninstall the app and delete the .oneconsole folder in your user profile. See the Privacy Policy.
